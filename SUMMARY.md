## 🚀 Como Usar

### Instalação Rápida
```bash
git clone https://github.com/CauanAmorimGomes/portfolio.git
cd portfolio
npm install
npm run dev
```

### Personalização (3 passos)
1. Edite `src/constants/portfolio-data.ts` (dados pessoais)
2. Ajuste cores/tema conforme preferência
3. Adicione seus projetos reais

### Deploy (1 comando)
```bash
# Vercel
vercel --prod

# Ou Netlify
netlify deploy --prod
```
