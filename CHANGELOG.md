# 📝 Changelog

Todas as mudanças notáveis neste projeto serão documentadas neste arquivo.

## [1.0.0] - 2026-01-XX

### ✨ Adicionado
- **Estrutura inicial do projeto**
  - Configuração React + TypeScript + Vite + Tailwind CSS
  - Estrutura de componentes modulares
  - Sistema de roteamento por scroll

- **Componentes principais**
  - Header com navegação fixa e menu mobile
  - Hero com efeito typewriter
  - About com informações pessoais
  - Skills com barras de progresso animadas
  - Projects com sistema de filtros
  - Contact com formulário funcional
  - Footer com links e redes sociais

- **Funcionalidades**
  - Tela de loading animada
  - Navegação suave entre seções
  - Detecção automática de seção ativa
  - Sistema de filtros de projetos por tecnologia
  - Formulário de contato com validação
  - Links para GitHub e redes sociais
  - Scroll to top button

- **Design**
  - Tema dark com gradientes purple/pink
  - Totalmente responsivo (mobile-first)
  - Animações e transições suaves
  - Hover effects interativos
  - Scrollbar customizada

- **SEO e Acessibilidade**
  - Meta tags otimizadas
  - Open Graph tags
  - Twitter Cards
  - Semantic HTML
  - ARIA labels

- **Documentação**
  - README completo
  - Documentação de componentes
  - Comentários inline no código
  - Changelog

- **Utilitários**
  - Hooks personalizados (useScrollAnimation)
  - Funções helpers (scroll, debounce, throttle)
  - Constantes centralizadas
  - Sistema de tipos TypeScript

### 🎨 Estilização
- Tailwind CSS para estilização
- Gradientes customizados
- Animações CSS personalizadas
- Scrollbar estilizada

### 📦 Dependências
- React 18
- TypeScript
- Vite
- Tailwind CSS

### 🔧 Configuração
- ESLint configurado
- TypeScript strict mode
- Vite para build otimizado
- Git ignore configurado
